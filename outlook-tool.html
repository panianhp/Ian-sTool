📧 Outlook 郵件與行事曆

連結你的 Microsoft 帳號來查看郵件和行事曆事件。需要先設定 Azure App Registration。

⚙️ 首次使用設定指南

  1. 前往 Azure Portal - App Registrations
  2. 點擊「新增註冊」(New registration)
  3. 名稱輸入任意名稱（如 My Outlook Tool）
  4. 支援的帳戶類型選擇「任何組織目錄中的帳戶及個人的 Microsoft 帳戶」
  5. 重新導向 URI 選擇「單頁應用程式 (SPA)」，輸入 http://localhost 或你開啟此 HTML 的網址
  6. 註冊後，複製「應用程式 (用戶端) 識別碼」(Application Client ID)
  7. 在下方貼上 Client ID 並儲存
